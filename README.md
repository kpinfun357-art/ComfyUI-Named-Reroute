# ComfyUI 命名重定向（Named Reroute）

**版本：0.2.0**  
为 ComfyUI 提供类似 Unreal Engine「Named Reroute」的命名式数据连线：定义一个名称，其他位置的使用节点填写同名即可读取数据，不必在画布上保留跨区域长连线。

## 功能

- **定义 / 使用双节点**：`命名重定向 · 定义` 与 `命名重定向 · 使用`。
- **一个定义，多个使用**：同一个名称可被多个使用节点读取。
- **自动类型同步**：使用节点的输出类型会跟随定义节点来源的输出类型；支持普通 ComfyUI socket 类型以及自定义节点类型。
- **执行前解析**：排队执行时，插件把使用节点解析到定义节点的真实来源；虚拟节点不会进入执行提示词，也不会增加图像处理步骤。
- **工作流保存**：临时解析不会把隐藏的连线写进保存的工作流。
- **名称颜色**：同名定义/使用节点显示相同颜色，便于在复杂工作流中识别。
- **名称检查**：检查空名称、找不到定义、重复定义、未连接来源和循环引用。
- **无第三方依赖**：不需要安装额外 Python 包。
- **执行连接修复**：使用节点在排队前会在 API 提示词中映射到定义节点的真实来源，提交给服务器的连接引用是真实来源节点。

## 安装（ComfyUI Desktop / Windows）

1. 先退出 ComfyUI Desktop。
2. 找到当前 ComfyUI 实际使用的 `custom_nodes` 文件夹。它位于 ComfyUI 运行目录下；如果 Desktop 安装在自定义位置，请以该实例的运行目录为准，不要把插件放进另一个独立的 ComfyUI 副本。
3. 解压插件 ZIP。确保最终目录结构是：

   ```text
   custom_nodes/
   └── ComfyUI-Named-Reroute/
       ├── __init__.py
       ├── nodes.py
       ├── README_CN.md
       └── web/
           └── named_reroute.js
   ```

   **注意：不要多套一层目录。** 错误示例：`custom_nodes/ComfyUI-Named-Reroute/ComfyUI-Named-Reroute/__init__.py`。

4. 重新启动 ComfyUI Desktop。
5. 在节点搜索框搜索 `命名重定向`。如果没有出现，查看启动日志中是否有 `ComfyUI-Named-Reroute` 的导入错误，然后在浏览器页面执行一次强制刷新（`Ctrl+F5`）。

## 使用方法

### 例子：把一张图片提供给两个不同区域

1. 在图像来源节点（例如 `Load Image`）附近添加 **命名重定向 · 定义**。
2. 将 `Load Image` 的 `IMAGE` 输出连接到定义节点的 `value` 输入。
3. 在定义节点的 `name` 中填写：`高清修复图`。
4. 在工作流另一处添加 **命名重定向 · 使用**，将它的 `name` 也填写为 `高清修复图`。
5. 将使用节点的 `value` 输出接到需要图片的节点，例如预处理、放大或预览节点。
6. 如有需要，再添加更多同名的使用节点；它们都会读取同一个来源。
7. 点击 Queue 执行。画布上不需要跨越整个工作流的长连线。

### 规则

- 名称不区分大小写，首尾空格会被忽略；建议使用简短、易辨认的名称。
- 每个名称只能有一个定义节点；可以有任意多个同名使用节点。
- 定义节点的 `value` 必须连接一个有效来源。
- 如果更改定义节点的名称，也要同步更改相应使用节点的名称。
- 可以把一个使用节点接入另一个定义节点的 `value`，插件会尝试递归解析；如果形成循环引用，执行前会提示错误。
- 使用节点输出类型会跟随来源类型。若来源类型发生变化，建议检查下游连接是否仍然合理。

## 当前版本的限制

- 0.2.0 主要针对 **ComfyUI 经典 LiteGraph 节点画布**设计。ComfyUI Desktop 的不同版本、实验性 Nodes 2.0 / Vue 画布或大幅修改前端的扩展可能改变内部图结构；首次使用请用简单工作流测试。
- 当前版本按主画布的节点图进行名称解析；复杂子图 / 嵌套子图尚未作为正式支持目标。
- 这是一个兼容性修正版。代码已进行静态语法检查和提示词连接模拟；不同 ComfyUI Desktop 版本仍可能对前端扩展接口有差异，因此安装后请先按下面的测试流程验证。

## 安装后建议测试

1. 新建 `Load Image → 命名重定向 · 定义`，名称设为 `测试图像`。
2. 添加 `命名重定向 · 使用`，名称设为 `测试图像`，连接到 `Preview Image`。
3. 执行队列，确认能正常预览。
4. 再添加第二个同名使用节点连接到另一个下游节点，确认两处均能使用。
5. 保存工作流、重启 ComfyUI，再打开工作流重复测试。
6. 故意把使用节点名称改成不存在的名字，执行时应出现明确错误提示；修正名称后再次执行。

如果你从 0.1.0 升级，请先退出 ComfyUI，再删除旧的 `ComfyUI-Named-Reroute` 文件夹，解压 0.2.0 到同一个 `custom_nodes` 目录，最后重新启动并按 `Ctrl+F5` 刷新。

## 故障排查

- **搜索不到节点**：检查目录是否多套一层，确认 `__init__.py` 与 `nodes.py` 直接位于插件根目录；重启并查看启动日志。
- **提示前端扩展不可用 / 无法解析提示词**：在经典节点画布下重试，执行 `Ctrl+F5`，并确认 `web/named_reroute.js` 被加载。
- **出现“找不到定义节点”**：检查定义与使用节点名称是否完全一致（忽略大小写和首尾空格）。
- **出现“重复定义”**：搜索该名称，确保只有一个定义节点。
- **出现循环引用**：检查是否把使用节点接回同一名称定义链，形成环路。

## 文件

- `__init__.py`：插件入口
- `nodes.py`：节点注册
- `web/named_reroute.js`：前端类型同步与执行前连线解析
- `README_CN.md`：中文说明
